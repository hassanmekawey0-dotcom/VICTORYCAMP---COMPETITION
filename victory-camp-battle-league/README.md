# VICTORY CAMP — THE BATTLE LEAGUE

Responsive front-end concept for a military-themed gym competition platform.

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server.

## Structure
- `index.html` — semantic page structure and content
- `css/style.css` — design tokens, sections, responsive layout
- `js/main.js` — mobile navigation, leaderboard tabs, demo form
- `assets/images/` — optional local image assets
- `assets/fonts/` — optional local font files

## Prototype interactions
- Switch leaderboard between individual athletes and squads.
- Open/close mobile navigation.
- Submit the demo enlistment form for an on-screen confirmation.

## Important
All athlete names, squad names, points, rankings, season numbers and deadlines are sample data. The form does not transmit or store information. External image URLs and Google Fonts require an internet connection.

A production platform will need authentication, athlete profiles, database storage, admin result verification, team management, scoring rules, season scheduling and a real registration endpoint.
